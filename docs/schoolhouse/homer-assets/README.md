## Design Notes

Both assets are **SVG format** — fully scalable, no quality loss at any screen size. They will render crisply on everything from a phone to a classroom projector to a Raspberry Pi display.

The banner (`homer-banner-math-science.svg`) establishes Mr. Homer's visual identity: energetic, science-forward, approachable for kids. The "ASK HOMER" search bar element is a natural UI metaphor — students literally type questions to Homer.

The AI intro slide (`homer-ai-intro-slide.svg`) is ready to use as the opening frame of the AI literacy module. The copy is already age-appropriate and engaging.
