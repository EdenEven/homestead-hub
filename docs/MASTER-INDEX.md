## 2. Infrastructure & Operations (The "Mud and Muck" Reality)

This section documents the technical infrastructure, designed to survive billing cycles, platform outages, and limited funding.

*   **GitHub as Permanent Memory:** All documentation, code, and milestone tracking reside in this repository. If any external service fails, the blueprint remains secure here.
*   **Supabase Database Strategy:** While a local database exists, Supabase serves as the primary data store with automated backups to this repository, ensuring data resilience.
*   **The "Offline Goldmine" (Raspberry Pi):** The ultimate insurance policy. This package includes offline-capable models (like Qwable-9B) and core curriculum, offered as a standalone product for off-grid users and a backup for the community.
*   **Automated Content Publishing:** (To be fully documented) Workflows for managing scheduled blog posts and gated content, ensuring consistent publishing regardless of subscription status.
