## How to Post This on Facebook

1. Go to your A1 Homestead Hub Facebook page
2. Click **"Create post"**
3. Click the **"..."** (More options) button in the post composer
4. Select **"Document"** (or "Add to post → Document")
5. Upload the file: **A1-Homestead-Hub-Partner-Alignment-Statement.pdf**
6. Paste the post copy above into the text field
7. Publish

**Note:** Facebook document posts display a preview of the PDF cover page directly in the feed. Viewers can read the full document without leaving Facebook, or download it. This format gets significantly more engagement than a link post because the content is native to the platform — Facebook does not suppress it the way it suppresses external links.
